Личное приложение

Hermes Agent

Персональный ассистент для личного использования: напоминания, планирование дня, работа с календарём.

Коротко: приложение обращается только к Google Календарю владельца, хранит данные локально и никому их не передаёт.

Что это

Hermes Agent — персональное приложение для одного пользователя (владельца). Оно не является коммерческим продуктом, не предоставляется третьим лицам и не имеет регистрации публичных аккаунтов. Приложение работает на личном компьютере владельца и помогает вести расписание: создавать и изменять события, напоминать о тренировках, приёмах врачей и других делах.

Политика конфиденциальности

Действует с 2 ноября 2026 года.

1. Какие данные используются. Приложение запрашивает доступ к Google Календарю владельца — единственный разрешённый ресурс (scope https://www.googleapis.com/auth/calendar): просмотр событий, их создание и изменение. Доступ к Gmail, Google Drive, контактам, документам и таблицам не запрашивается.

2. Где хранятся данные. Учётные данные доступа (OAuth-токен) и рабочие данные хранятся локально на личном компьютере владельца в защищённом каталоге пользователя. Данные не отправляются на собственные серверы приложения — у приложения таких серверов нет.

3. Передача третьим лицам. Данные не продаются, не передаются и не публикуются. Доступ третьим лицам не предоставляется. Обращения к API Google осуществляются напрямую с устройства владельца.

4. Использование данных. Данные календаря используются исключительно для функций, которые ожидает владелец: утренняя сводка событий, напоминания, создание и изменение событий по его запросу. Использование соответствует Google API Services User Data Policy, включая требования Limited Use.

5. Хранение и удаление. Владелец может в любой момент прекратить доступ, отозвав разрешения приложения на странице myaccount.google.com/permissions. После отзыва доступ к календарю немедленно прекращается; локальную копию токена владелец удаляет с устройства.

6. Контакт. По любым вопросам, связанным с данными и работой приложения: guvatara@gmail.com

English summary

Hermes Agent is a personal, single-user assistant. It requests access to the owner's Google Calendar only (auth/calendar scope) to read, create and update events for the owner's own planning and reminders.

Credentials and all data are stored locally on the owner's own computer. No data is transmitted to any application server, sold, or shared with third parties. Access can be revoked at any time at myaccount.google.com/permissions. Use complies with the Google API Services User Data Policy, including Limited Use requirements.
