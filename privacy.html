Политика конфиденциальности

Hermes Agent · личное приложение · действует с 2 ноября 2026 года

Настоящая политика описывает, какие данные использует приложение Hermes Agent (далее — Приложение), как они хранятся и как владелец может прекратить их обработку. Приложение является персональным, используется одним владельцем и не предоставляется третьим лицам.

1. Какие данные используются

Приложение запрашивает доступ к Google Календарю владельца — единственный разрешённый ресурс, scope https://www.googleapis.com/auth/calendar:

  • просмотр событий календаря владельца;
  • создание событий по запросу владельца;
  • изменение и удаление событий по запросу владельца.

Доступ к Gmail, Google Drive, контактам, документам и таблицам не запрашивается и не используется.

2. Как используются данные

Данные календаря используются исключительно для функций, которые ожидает владелец: утренняя сводка событий дня, напоминания о делах, создание и изменение событий по его просьбе. Приложение не использует данные для рекламы, профилирования или аналитики.

3. Где хранятся данные

Учётные данные доступа (OAuth-токен) и рабочие данные хранятся локально на личном компьютере владельца в защищённом каталоге пользователя. У Приложения нет собственных серверов: запросы к Google API выполняются напрямую с устройства владельца, и данные не передаются на сторонние серверы.

4. Передача третьим лицам

Данные не продаются, не передаются и не публикуются. Доступ третьим лицам не предоставляется. Использование данных ограничено случаями, прямо описанными в настоящей политике, и соответствует Google API Services User Data Policy, включая требования Limited Use.

5. Хранение и удаление

Владелец может в любой момент отозвать доступ Приложения, открыв myaccount.google.com/permissions и удалив доступ для приложения. После отзыва доступ к календарю прекращается немедленно. Локальную копию токена владелец удаляет с устройства в любой момент.

6. Соответствие требованиям Google

Приложение соблюдает Google APIs Terms of Service и настоящая политика соответствует Google API Services User Data Policy, включая требования Limited Use. Приложение не использует Google API для создания или распространения AI-generated non-consensual intimate imagery (AI NCII), не генерирует изображения, видео и аудио, не обучает модели на данных Google и не использует их для рекламы или профилирования.

Доступ к этой странице открыт публично: вход, регистрация и авторизация не требуются.

7. Изменения политики

Актуальная версия политики всегда доступна на этой странице. Дата последнего обновления указана вверху.
